# EasyLock 0.8.2 Preview 1 · 构建 13

免费、离线的 macOS 文件与文件夹加密工具。最低 macOS 14，支持 Apple Silicon 与 Intel。

## 本次更新

- 启用且可用的 Touch ID 优先用于解密；打开解密面板自动请求一次指纹，取消后可以使用密码或恢复密钥。
- 支持在应用内按空格验证身份后预览加密文件、浏览文件夹；图片支持适合窗口和放大查看。
- 修复 Quick Look 组件关闭时的崩溃路径，固定预览布局，减少加载后位置变化。
- Finder 大尺寸缩略图显示上锁状态、双击解密方法和应用内说明入口，小尺寸显示锁图标。
- 关闭或锁定应用时清理应用管理的临时预览副本。系统或第三方预览缓存无法保证清除。

## 下载与升级

下载 `EasyLock-0.8.2-preview.1-macOS-universal-dev.zip`，解压后将 EasyLock.app 放到固定位置。GitHub 的 Source code 下载项是源码。

先等待加解密任务完成并正常退出旧版，再替换应用。保留密码、恢复密钥和独立文件备份，不要同时运行多个开发副本。旧版本 Release 和二进制包已被本版替代，源码提交历史保留。

## 发布状态与限制

这是开发签名、未经 Apple 公证的预发布测试版，不是正式发行版。其他 Mac 可能阻止运行；不要关闭系统安全保护，可从对应标签使用 Xcode 构建或等待正式公证版。

构建、离线权限及签名完整性检查通过。Quick Look 生命周期及预览控制器重复加载测试通过，系统缩略图服务已实际生成说明卡片。完整 Finder 空格预览、指纹验证以及 Intel 真机兼容性仍需实机验收，尚未完成独立安全审查。请先使用有备份的测试文件。

本版不改变密文格式。Touch ID 使用本机保存的主密码，不能解密由其他密码加密的文件，也不能替代异机恢复所需的密码或密钥。
