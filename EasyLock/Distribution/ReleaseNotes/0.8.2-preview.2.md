# EasyLock 0.8.2 Preview 2 · 构建 31

免费、离线的 macOS 文件与文件夹加密工具。最低 macOS 14，下载包同时包含 Apple Silicon 和 Intel 架构。

## 本次更新

- 新增本机文件浏览，可选择目录、搜索、排序、前进后退、多选并进行加密、解密和预览。
- 简化主界面为加密文件、本机文件和设置；默认采用列表，保留网格切换与按需展开的详情。
- 预览使用独立原生窗口，支持调整大小、空格与 Esc 关闭；图片居中显示，缩放工具按需显示。
- 启用且可用的 Touch ID 优先用于身份验证，取消后可使用对应密码；新密码和恢复密钥确认仍需手动输入。
- 修复只读临时目录清理失败，包含私密预览关闭与异常退出后的残留清理。
- 修复更换目录失败时浏览状态错乱；大图片采用后台限尺寸解码。
- 改进 Finder 服务接收文件选择与加解密入口。

## 下载与升级

下载 `EasyLock-0.8.2-preview.2-macOS-universal-dev.zip`，解压得到 EasyLock.app。Source code 是源码，不是安装包。可使用附带的 SHA256SUMS.txt 核对下载文件。

等待加解密任务结束，正常退出旧版，再替换应用。保留密码、恢复密钥和独立备份，不要同时运行多个版本。本版没有改变密文格式，更改主密码不会给旧文件更换密码。

## 使用状态

**这是开发签名、未经 Apple 公证的预发布测试版。** 适合在有独立备份的测试资料上试用，尚不建议作为重要文件唯一的保护方式。其他 Mac 可能阻止启动；不要关闭系统安全保护，可以使用 Xcode 从此标签构建，或等待公证版本。

程序化回归覆盖内容与元数据往返、损坏密文、取消与进程中断恢复、只读临时目录清理、目录导航、图片尺寸限制及预览窗口生命周期。真实沙盒中的 DOCX、文件夹和隔离属性往返已验证。双架构构建、离线权限和签名完整性检查通过。

完整 Finder / Touch ID 真机操作、Intel 与最低系统实机兼容性、独立安全审查及下载后的 Gatekeeper 验收仍待完成。编译、测试和签名完整性不等于这些验收通过。

关闭预览会清理应用临时副本；异常退出后下次启动清理。系统或第三方预览缓存、备份及快照可能保留明文。Touch ID 使用本机保存的主密码，不能替代跨电脑恢复所需的密码或密钥。
