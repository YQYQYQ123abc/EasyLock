# EasyLock 0.8.1 Preview 1

免费、离线的 macOS 文件加密工具。此版本主要更新界面，应用内部版本为 **0.8.1（build 9）**。

## 下载前请读

这是**开发签名、未公证的预发布测试包**，最低 macOS 14，包含 Intel 与 Apple Silicon 架构。其他 Mac 可能被系统阻止运行；请等待公证版本，或使用 Xcode 从对应标签构建。不要关闭系统安全保护。

请下载 `EasyLock-0.8.1-preview.1-macOS-universal-dev.zip`；GitHub 自动生成的 Source code 是源代码，不是安装包。解压后可见 EasyLock.app 和使用说明。仅使用有独立备份的测试文件。

## 界面更新

- 居中解锁页：圆角密码输入、Touch ID 入口、蓝紫渐变背景。
- 文件页：窄侧栏、文件列表与详情分栏，支持多选、全选及批量解密。
- 搜索与筛选：显示全部记录或需要检查的记录；改变搜索/筛选时取消隐藏项目的选择。
- 设置页：分组展示登录、恢复密钥、通用和关于；设置状态来自真实配置。
- 视觉调整：轻量边框、深浅色适配，尊重减少动态效果设置。
- 不展示模拟文件、虚构进度或未经记录的密码版本；修改后缀的提示改为真实恢复方式。

## 升级与使用

1. 等待当前加解密任务结束，确认没有待恢复任务，再正常退出旧版本。
2. 保留密码、恢复密钥和文件备份，替换原安装位置的应用；不要同时运行多个开发版本。
3. 若系统阻止开发签名包运行，请保留旧版并等待正式签名版本，或自行构建源码。

本次不改变密文格式、加密算法和文件替换流程。更改主密码不会更改旧文件的密码；恢复密钥仅适用于启用后新加密的文件。Touch ID 不能替代异机恢复所需的密码或密钥。
