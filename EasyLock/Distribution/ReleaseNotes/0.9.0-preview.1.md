# EasyLock 0.9.0 Preview 1 · 构建 33

免费、离线的 macOS 文件与文件夹加密工具。最低 macOS 14，下载包同时包含 Apple Silicon 和 Intel 架构。

## 本次更新

- 全新浅色、信号蓝界面：白色卡片、柔和边框和蓝色操作强调，同时保留 EasyLock 的盾牌识别。
- 采用新的 EasyLock2 应用图标，并同步到侧栏、欢迎页、Finder 文件图标、Quick Look 和桌面小组件。
- 概览改为自适应三列布局：指标、保险箱状态、安全检查、最近文件和 7 天登记模块不再使用固定卡片高度。
- 移除概览卡片的外阴影并增加模块间距，修复卡片边缘视觉粘连和页面切换残影。
- 加密文件页改用白色卡片、蓝色文件图标、选中态和摘要数据条；本机文件页同步统一图标与间距。
- 设置页、欢迎页、详情面板和弹窗统一了蓝色图标底板、按钮和页面标题层级。
- Quick Look 预览卡直接使用应用图标；Finder 缩略图重做已上锁、大尺寸信息和无法识别三种状态；`.easylock` 文件图标与桌面小组件同步更新。
- 构建输出改到项目工作区，避免生成 asset symbol 时写入全局 DerivedData 的权限问题。

本版未改动加解密算法、文件格式或文件替换流程；已有密文仍可用原密码或对应恢复密钥解密。更改主密码仍然不会给旧文件换密码。

## 下载与升级

下载 `EasyLock-0.9.0-preview.1-macOS-universal-dev.zip`，解压得到 EasyLock.app。Source code 是源码，不是安装包。可使用附带的 SHA256SUMS.txt 核对下载文件。

等待加解密任务结束，正常退出旧版，再替换应用。保留密码、恢复密钥和独立备份，不要同时运行多个版本。

## 使用状态

**这是开发签名、未经 Apple 公证的预发布测试版。** 适合在有独立备份的测试资料上试用，尚不建议作为重要文件唯一的保护方式。其他 Mac 可能阻止启动；不要关闭系统安全保护，可以使用 Xcode 从源码构建，或等待公证版本。

双架构构建、签名完整性检查和既有自动化回归已完成。完整 Finder / Touch ID 真机操作、Intel 与最低系统实机兼容性、独立安全审查及下载后的 Gatekeeper 验收仍待完成。编译、测试和签名完整性不等于这些验收通过。

关闭预览会清理应用临时副本；异常退出后下次启动清理。系统或第三方预览缓存、备份及快照可能保留明文。Touch ID 使用本机保存的主密码，不能替代跨电脑恢复所需的密码或密钥。
