# EasyLock 0.8.2 Preview 3 · 构建 32

免费、离线的 macOS 文件与文件夹加密工具。最低 macOS 14，下载包同时包含 Apple Silicon 和 Intel 架构。

## 本次更新

- 全新黑白界面：从应用图标出发，采用纸张/墨色、矢量盾牌、同心描边和克制的留白；原有蓝色玻璃拟态样式已移除。
- 重做侧栏、欢迎与解锁、加密文件、本机文件、设置、详情面板、拖放区和全部操作弹窗。
- 加密文件卡片和列表改用单色文件线稿，锁定状态使用统一的墨色封印标识。
- 设置拆分为安全与解锁、常规、恢复与检查、主题、关于等独立分区。
- Quick Look 锁定卡片、Finder 缩略图、桌面小组件和强调色同步改为新视觉。
- 修复文件夹预览窗口的左右分栏未撑满、顶部出现大块空白的问题；隐藏重复的原生标题栏标题。
- 文件夹预览不再显示隐藏文件，并按文件夹优先排序，和“本机文件”浏览器的行为一致。
- 更新官网首页、支持页和隐私页的界面与截图。

本版未改动加解密算法、文件格式或文件替换流程；已有密文仍可用原密码或对应恢复密钥解密。更改主密码仍然不会给旧文件换密码。

## 下载与升级

下载 `EasyLock-0.8.2-preview.3-macOS-universal-dev.zip`，解压得到 EasyLock.app。Source code 是源码，不是安装包。可使用附带的 SHA256SUMS.txt 核对下载文件。

等待加解密任务结束，正常退出旧版，再替换应用。保留密码、恢复密钥和独立备份，不要同时运行多个版本。

## 使用状态

**这是开发签名、未经 Apple 公证的预发布测试版。** 适合在有独立备份的测试资料上试用，尚不建议作为重要文件唯一的保护方式。其他 Mac 可能阻止启动；不要关闭系统安全保护，可以使用 Xcode 从源码构建，或等待公证版本。

双架构构建、离线权限检查、签名完整性检查和既有自动化回归已完成。完整 Finder / Touch ID 真机操作、Intel 与最低系统实机兼容性、独立安全审查及下载后的 Gatekeeper 验收仍待完成。编译、测试和签名完整性不等于这些验收通过。

关闭预览会清理应用临时副本；异常退出后下次启动清理。系统或第三方预览缓存、备份及快照可能保留明文。Touch ID 使用本机保存的主密码，不能替代跨电脑恢复所需的密码或密钥。
