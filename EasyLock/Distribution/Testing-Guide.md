# EasyLock 测试版验收步骤

仅使用有独立备份的测试资料。开发签名包不等于已公证的正式安装包。以下项目必须在真机实际完成后记录结果，不能以编译通过代替。

## 日常使用

1. 创建测试主密码，分别添加普通文件和多层文件夹；拖入多项，再试 Finder 服务入口。
2. 加密后检查原位置仅留下对应 .easylock；空格预览与缩略图不得出现原内容。
3. 解密并与备份比对文件内容、名称、目录结构、标签及其他所需属性。
4. 开启恢复密钥，另外新加密一个文件；在另一台 Mac 上分别用密码与密钥恢复。确认旧文件仍需旧凭据。
5. 改密码后验证旧文件仍可用旧密码解密；误输密码或密钥时密文必须保持完整。

## 面板与会话

- 快速重复点击添加、连续拖放、双击多个密文、打开帮助再触发其他操作：只显示一个面板，后续请求不会丢失或覆盖当前输入。
- 取消面板后再添加，操作完成后连续关闭结果，关闭主窗口再打开密文。
- 任务中锁屏、睡眠、切换用户或达到闲置时间：安全结束或回滚当前任务，重新访问要求解锁。
- Touch ID 取消/失败后可继续用密码；关闭 Touch ID 后不能再使用先前保存的快捷凭据。

## 异常恢复

- 使用独立的测试磁盘或测试卷验证空间不足，不要把系统盘填满。
- 在仅包含测试副本的外置盘上模拟断开；对大文件加密时强制结束测试进程并重启应用。
- 恢复后必须能找到可验证的原件或可解密密文；不要手动删除待恢复事务目录。
- 同名目标、只读目录、链接或不支持的文件类型应给出提示，不覆盖其他文件。
- 如发现丢失、恢复失败或不确定状态，停止发行，保存测试数据与错误信息以复现。

## 安装与系统集成

在 Apple Silicon、Intel、macOS 14 与当前系统分别记录：系统版本、架构、包版本、测试日期、通过/失败、复现步骤。
检查首次安装、更新、Finder 扩展注册、登录启动、小组件添加和数量隐藏、离线帮助与隐私说明。最终发行包另做 Gatekeeper、公证与商店验证。

反馈只需版本、系统、操作步骤和去除私人信息的错误提示。不要发送密码、恢复密钥、原始私人文件或包含完整路径的未处理日志。
