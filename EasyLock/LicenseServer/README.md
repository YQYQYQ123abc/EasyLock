# 三设备许可证服务（未部署）

本目录提供可运行的参考服务，官网客户端已实现请求签名和授权响应验证。没有支付回调、订单后台、账户恢复或公开部署。当前 App 未配置 endpoint 和公钥，激活入口明确显示未开放。

## 本地运行

使用 Python 3.11+ 创建虚拟环境并安装 requirements.txt。运行 `python server.py init` 生成本机私钥并显示客户端需要的 Base64 公钥；再运行 `python server.py issue` 签发一份许可证，最后 `python server.py serve` 启动仅监听 127.0.0.1:8787 的测试服务。私钥和数据库在 license-data，权限按 0600/0700 创建。不要将该目录提交或放入 App。

上线时将 HTTPS 完整路径配置为主 App Info.plist 的 `EasyLockLicenseEndpoint`（例如自有域名的 /v1/license），并将公钥配置为 `EasyLockLicensePublicKey`。域名尚未确定，工程没有填入任何占位线上地址。客户端拒绝 HTTP 与重定向；本地 HTTP 仅供服务端测试，不作为生产客户端配置。

## 协议和规则

- 一个许可证最多 3 个活跃设备，SQLite BEGIN IMMEDIATE 将检查与插入放在同一事务，重复激活同一设备不增加席位。
- 许可证为随机高熵凭据，数据库只存 SHA-256。设备使用 Ed25519 密钥，ID 是设备公钥的 SHA-256；客户端密钥和许可证在本机钥匙串。
- POST JSON 为 `{payload, signature}`，两字段均 Base64。签名对象是 payload 解码后的原始 JSON 字节，不需要跨语言 JSON 排序一致。
- activate/inspect/refresh/deactivate 请求均携带许可证、公钥、时间戳、随机 nonce、设备名称及可选 targetDeviceID。验证请求签名、五分钟时间窗和成功请求 nonce 去重。
- activate、inspect 与解绑设备需要持有许可证并签名请求；refresh 要求请求设备已激活。名额已满的新电脑可以先查看设备并释放旧名额，无需先激活。用户持有许可证相当于拥有管理权限，分享许可证也会分享管理能力。
- 响应用服务器 Ed25519 私钥签名，绑定许可证和当前设备，包含三台上限、设备列表、签发和过期时间。客户端验证签名、设备、期限和数量；缓存最多 7 天。
- 远程解绑或撤销后，离线旧凭据可能继续显示有效至过期，不宣称实时强制三台在线限制。过期不影响解密。开发预览版暂不对加密设付费门槛。

## 上线前剩余事项

正式部署必须配置 TLS 反向代理、请求频率限制/并发上限、可靠数据库备份、密钥安全保管和轮换、付款后幂等签发及退款撤销、购买凭证找回流程。内置 HTTP server 仅作开发参考，不能直接暴露公网。私钥丢失不能用旧公钥继续签发。

商店版不编译官网激活客户端，商品 ID 和 StoreKit 购买尚待配置。三设备规则在商店购买方案中的适用性仍需审核确认。

运行 `python -m unittest -v test_server.py` 测试并发上限、去重、重放、签名篡改、时间窗、解绑后刷新拒绝及再次激活。
