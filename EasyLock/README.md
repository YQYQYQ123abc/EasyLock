# EasyLock · macOS 开发预览版 0.8

当前发行方向为**免费、离线、无需账号或激活、无设备数量限制**。两个渠道默认均不编译许可证界面或联网授权客户端，应用不申请出站网络权限。历史许可证源码与服务端仅保留供参考，不属于现行发布流程；下文历史版本中涉及购买或授权接入的计划已取消。发布进度以 [Distribution/README.md](Distribution/README.md) 为准。

使用 Xcode 打开 `EasyLock.xcodeproj`，选择 EasyLock scheme，运行（⌘R）。最低 macOS 14。

## 添加与拖放

首页分别提供“添加文件”和“添加文件夹”，文件夹窗口可以多选整个目录。
也可从 Finder 将一个或多个本地文件/文件夹拖入主窗口，松开后进入确认流程。
已有密文（包括手动改过后缀的密文）会被识别并进入解密流程；锁定状态下拖入的项目在解锁后继续处理。
不接受网页链接、纯文本或临时文件副本作为原地加密输入。

## 本机文件浏览

支持目录前进/后退、卡片与列表切换、名称/大小排序和项目右键菜单。⌘F 聚焦搜索，⌘R 刷新当前目录；刷新保留仍存在的选中项。进入无法读取的目录时保留之前的位置与列表。视图与排序偏好在本机保存。

解锁应用后进入“本机文件”，选择并授权个人主目录、文稿或其他文件夹，即可浏览当前目录和子目录。卡片显示真实文件名、大小及加密状态，支持搜索、筛选、Command 多选和批量加密/解密；操作完成后刷新当前目录。所有操作使用现有确认、验证与原地恢复流程。

仅列出当前目录，不递归扫描整台电脑；隐藏文件不显示，超过 5,000 项的目录需选择更具体的子目录。应用程序、文件包、符号链接及未下载的云端文件标为不可操作。保存上次浏览目录的本地授权书签；“关闭目录”忘记浏览位置，但不删除文件或已有事务恢复授权。文件内容不上传。

本机文件卡片的眼睛按钮或选中单个项目后按空格键可预览。普通文件使用应用内图片显示或系统 Quick Look；文件夹显示直接子项概览，隐藏项目不显示。密文需先验证，临时解密预览沿用私密预览清理流程。系统 Quick Look 可能缓存预览。

侧栏设置分为常规、安全与解锁、恢复与检查、主题及关于。主题可跟随系统或指定浅色、深色。

## 原地加密与恢复

- `合同.pdf` → 同一目录中的 `合同.pdf.easylock`。
- `私人照片/` → 同一目录中的 `私人照片.easylock`，是一个密文文件。
- 解密恢复加密前的名称、后缀、目录结构和内容，成功后移除密文。
- 不再选择其他输出位置。App Sandbox 首次可能要求授权文件所在目录，以允许创建、重命名和删除同级项目。
- 同名冲突中止操作，不覆盖其他文件。旧版副本若旁边仍有同名原件，需要先移开冲突项目。
- 源目录与其子项同时选中时只处理外层目录，防止重复加密。

## 实际保存的内容

普通文件的数据逐字节归档，不重新编码 PDF、图片、Office 文档或其他格式。
版本 2、3、4 将以下信息一起加密：原名称及后缀、目录结构、文件字节、权限、用户及组、创建/修改/访问时间、支持的文件标志、扩展属性（含 Finder 标签、FinderInfo 和资源分支）、ACL。

加密会实际恢复一次并比对文件内容与可恢复元数据；源文件移动到事务目录后再次比对，全部通过才提交密文并清理原件。解密执行相反流程。

这不是文件系统快照：恢复后的 inode、ctime、物理块位置、克隆/稀疏布局等底层状态会不同。符号链接、硬链接、特殊文件、其他用户的文件、压缩/不可变/云占位等特殊标志暂不支持。无法读取或完整恢复元数据时中止，不默默丢弃它们。`com.apple.macl`（系统访问授权记录）与 `com.apple.provenance`（系统来源记录）保留在归档中，但不重写、不删除目标上现有的对应属性，也不要求其值逐字节相同。它们由 macOS 管理，重放到新文件可能导致 Operation not permitted。
普通扩展属性、FinderInfo、标签和资源分支仍严格恢复与比对。
`com.apple.quarantine` 单独处理：归档保留原始信息，但 App Sandbox 不允许重放旧的原始隔离标记。恢复时保留系统已生成的隔离状态；如果原文件受隔离且恢复文件尚无标记，使用公开的 NSURL quarantineProperties 接口建立隔离状态，并检查其存在。不会删除已有隔离标记，也不会关闭沙盒。隔离记录的标志、时间和事件编号可由 macOS 更新，不承诺字节相同。
其他扩展属性写入错误仍中止替换并显示具体属性名。

加密前关闭正在写入源文件的程序。NSFileCoordinator 和提交前校验保护配合系统协调的访问，但不能阻止绕开协调机制的其他程序在最后时刻继续写入。历史缓存、快照、备份和其他明文副本不在此次加密范围内。

## 手动修改后缀

文件识别检查内容中的 EasyLock 标识，不依赖文件名后缀。

- 将密文改成 `.jpg`、`.pdf` 或无后缀，不会恢复内容，也不能绕过密码。
- 将普通文件改成 `.easylock`，不会成为有效密文。
- 导入、选择文件和 Finder 服务均可识别改名后的密文，引导解密。
- EasyLock 运行时，监听已登记且获得访问授权的文件；收到重命名事件并发现后缀变化时，提示解密并更新记录。
- EasyLock 退出、文件未登记或未获得访问权限时，不保证出现提醒。
- Finder 通过扩展名等信息选择默认应用。改名后其他软件可能报告格式无效，EasyLock 无法接管所有软件的打开操作，也不会抢占所有 PDF/图片的默认关联。

## 事务与异常恢复

同卷私有目录 `.easylock-transaction-<UUID>` 保存 `recovery.json` 和暂存数据。
密文及恢复文件提交使用不覆盖目标的同卷重命名，发布目录同步后才清理输入。
正常完成会删除该目录。操作失败会尝试把完整输入移回原位置。

若应用或系统突然终止，暂存目录可能仍存在。`recovery.json` 记录操作、原名称、结果名称及阶段：

- `original` 是加密过程中暂存的原件；若原位置为空，可按记录的原名称恢复它。
- `encrypted-original` 是解密过程中暂存的密文；可按记录名称恢复，或在 EasyLock 中导入该文件。
- 已发布的 `.easylock` 可独立解密，无需本地数据库。
- 不要在未核对恢复结果时删除事务目录，也不要将它覆盖到另一个同名文件上。

启动时自动检查已记录且可访问的原文件所在目录，在“安全与设置 → 中断任务恢复”中列出未完成任务。每次新任务开始前，先持久保存所在目录的授权书签；旧版已授权目录也会检查。只检查这些目录的直接子项，不扫描整块磁盘。已发布但来不及登记的 `.easylock` 密文会按内容标识识别并补入列表；已经手动改为其他后缀、且未登记的文件仍需手动导入。离线或授权失效会显示提示；可用“检查恢复目录”选择其他位置。

恢复操作会重新读取记录、检查阶段和冲突，用不覆盖的重命名将原件或密文放回原位置。已经发布的结果保留；恢复后的明文副本需要用户自行确认。尚未移动输入的任务可清理临时副本。若中断发生在递归清理原件期间，残留内容可能不完整，不会提供“恢复完整原件”的操作，而是保留数据并提供 Finder 检查入口。

清理失败明确显示“需要处理”和恢复目录路径，可能仍有明文，不能视为保护完成。事务日志、文件和关键目录会同步到磁盘，但实际断电及硬件故障仍受文件系统和设备行为影响；已做真实进程退出测试，不将其等同于物理断电测试。

## 其他功能与限制

中文 SwiftUI 界面、主密码、会话锁定、搜索、多选/全选解密、文件书签、锁形图标、文件关联、Finder 系统“服务”入口和登录启动设置。

AES-256-GCM；PBKDF2-HMAC-SHA256 600,000 次、16 字节随机盐。头部版本参与认证。
版本 2：`EASYLOCK\0` + `02` + 盐 + CryptoKit AES-GCM combined；密文内部为二进制 plist。
版本 3（未启用恢复密钥时的新加密格式）：`EASYLOCK\0` + `03` + 16 字节盐；后续为加密的文件清单、最多 1 MiB 的数据块、加密结束标记。每帧使用 8 字节大端长度和 AES-GCM 密文/tag；nonce 为 4 字节零加 8 字节帧序号，AAD 为头部加帧序号。每个归档使用新随机盐派生密钥。清单加密保存名称、元数据、文件长度及 SHA-256，数据帧绑定顺序，严格验证结尾与 EOF，拒绝删除、重排、重复、追加和损坏。
仍可解密版本 1、2；版本 1 未保存的元数据无法补回，解密完成时会明确提示。旧版 EasyLock 无法打开版本 3 文件。

新版本不再把所有文件内容装入内存，支持超过 64 MiB 的文件及文件夹；文件内容按 1 MiB 分块读写。目录仍最多 10,000 个条目，扩展属性总量上限 64 MiB，加密清单上限 72 MiB；不会静默丢弃超限元数据。
加密时需要同时容纳原件、暂存密文和用于实际恢复校验的副本，请预留足够磁盘空间（不压缩时通常需要约两倍源内容的额外空间）。写入或校验失败时保留原输入，回滚失败会报告恢复位置。主密码不以明文落盘，当前会话内存中保留密码；本地索引保存明文名称/路径。文件内容不上传。

## 任务进度与取消

底部显示当前项目、批量完成数、当前阶段的字节进度及估算剩余时间。估算按当前阶段计算，不是整个批量任务的承诺时间。
支持检查、加密、恢复与校验期间取消，之后的项目不再开始。进入原件移动与结果发布的提交步骤后，会先安全完成当前项目；大文件提交前的再次校验可能仍需等待。旧版本 1、2 的单次解码不能分块取消，但提交前仍检查取消状态。
完成后逐项显示成功、失败、取消、未处理或需要检查的信息；“添加项目 → 查看上次任务结果”可重新打开结果。

## 自动锁定

默认在应用内闲置 5 分钟后锁定，可选 1、5、15 分钟或关闭闲置计时。只监听应用内输入，不申请全局输入监控或辅助功能权限。睡眠、屏幕关闭、会话切换也触发锁定；屏幕锁定通知作为补充信号。
锁定立即隐藏界面中的敏感字段、关闭凭据窗口，并请求取消当前批量任务；已经进入文件提交步骤时先安全完成当前项目。任务所需凭据会保留到该步骤退出，不承诺 Swift 字符串内存被立即物理擦除。锁定应用不会重新加密磁盘上已经解密的文件。
自动化覆盖闲置时钟和模拟系统事件，实际锁屏/唤醒与 Touch ID 联动仍需在目标系统验证。

## 空间预检查与恢复副本

确认加密窗口显示源项目所需额外空间和当前可用空间。事务开始前再次检查；内容、属性、目录条目和分块开销均纳入保守估算。估算不等于空间预留，其他应用占用磁盘后仍可能写入失败，由事务回滚处理。不主动下载 iCloud 占位文件，提示先在 Finder 下载。
解密窗口可选“恢复到其他位置，并保留密文”。在所选目录私下恢复、验证，再不覆盖发布。原密文始终保留；如有同名目标，选择另一个目录。跨文件系统无法保留要求的属性时中止，不悄悄降低保护标准。

## 主密码和恢复密钥

“安全与设置”支持更改主密码：验证当前密码后更新本机登录凭据，并关闭旧的 Touch ID 凭据。更改只影响登录及以后加密的文件，已有文件仍需原加密密码。界面要求用户确认这一点；不会冒充已给所有密文换密码。
密码验证信息整组存储到本机私有目录的 `credential.json`；可读取以前保存在 UserDefaults 的盐和验证值。改密后清除旧验证信息。

启用恢复密钥时生成 `ELRK1` 私钥字符串及校验码，提供导出与重新输入确认。应用持久保存的只有公开部分，私钥不进入 UserDefaults、索引或钥匙串；创建窗口关闭后不提供再次显示。持有该密钥的人可以解密对应文件，应与密文分开保管。
只对启用后新加密的文件生效。更换恢复密钥不会修改旧文件，旧密钥必须保留。版本 1–3 文件需原密码；要增加恢复能力，先解密再使用已启用恢复密钥的新版重新加密。

版本 4：新随机 32 字节数据密钥加密内容；密码和恢复密钥分别封装同一数据密钥。恢复使用 CryptoKit X25519 + HKDF-SHA256 + AES-GCM，不依赖服务器或本地文件索引。头部包含 `EASYLOCK\0` + `04`、16 字节盐、32 字节恢复公钥、32 字节临时公钥、两个各 60 字节的 GCM combined 密钥封装。分块认证绑定整个头部；改动任何密钥封装都会导致验证失败。恢复私钥不会写入文件头。此格式仍需独立安全审查后才能作为正式发行承诺。

登录页提供“不登录，使用密码或恢复密钥解密文件”；双击密文也可进入独立解密流程。持有文件和对应凭据即可恢复，无需购买或先解锁本机应用账户。若仍有本机对应公钥，也可用匹配恢复密钥重设应用主密码；这不会更改旧文件密码。

## Touch ID

用主密码进入应用后，在“安全与设置”中启用 Touch ID，并完成系统指纹验证。
主密码保存到本机 Data Protection Keychain，使用 `biometryCurrentSet` 和 `WhenUnlockedThisDeviceOnly` 保护；不写入 UserDefaults、不同步 iCloud，不读取指纹数据。每次解锁使用新的认证上下文。

启用且可用时，应用登录、文件解密、私密预览及更改主密码时的当前密码验证，均优先弹出 Touch ID。每次进入验证界面只自动请求一次，取消后保留密码入口，不循环弹出。Touch ID 使用保存的本机主密码；其他密码加密的文件仍需输入对应密码。新密码的设置、确认及恢复密钥的抄录确认仍需手动输入。
关闭开关会删除该钥匙串条目；变更已录入指纹后可能失效，需要用主密码重新启用。取消、验证失败、不支持 Touch ID、钥匙串签名权限不足时都保留密码入口。

需使用 Xcode 的有效开发者签名运行，不能依靠未签名构建测试真实钥匙串访问。自动化不代替用户验证指纹。

已接入 Quick Look 预览与缩略图扩展，尚未接入许可证购买和自动更新服务。解密不受许可证状态限制。

- 预览只检查最多 11 字节的格式头；支持 01–04，显示固定锁定提示。未知版本、无效或不可读输入显示相应提示，不使用锁图标冒充有效密文。文件头识别不替代解密时的完整认证。
- HTML 不包含文件名、路径、密文载荷或远程资源；缩略图使用固定图形，不产生解密后的内容缓存。拒绝跟随符号链接，非阻塞打开并拒绝 FIFO、目录等特殊类型。
- Finder 服务与双击请求使用内存队列：界面建立前、操作中或确认窗口未关闭时保留请求；等待期间保留文件访问授权。进程退出后队列不保留。重复待处理请求合并；普通文件与密文混合选择时依次处理。
- 工具栏新增“使用帮助”，登录前也可查看。说明服务入口、文件夹授权、预览、密码/恢复密钥和改名后重新导入的操作。
- 正常 Finder 中空格预览、缩略图刷新、关闭全部窗口后的再次打开、多个开发版本并存时的扩展选择，仍需实机交互验收。单元测试和编译成功不代表系统已启用扩展。旧缓存不由 EasyLock 全局清理。

新增测试：预览隐私、所有格式版本、损坏/截断头、符号链接/FIFO、2 GiB 稀疏文件有限读取；外部请求冷启动前暂存、顺序、去重、URL 筛选与再次打开。


## 0.8 密码管理、雾蓝界面、许可证与小组件

- 设置密码后以及安全设置提供“保存到苹果密码”引导：用户主动复制并手动添加。当前 SDK 的 ASCredentialDataManager.save 标记 macOS unavailable；旧共享网页凭据接口需要正式关联域名，因此本版本不宣称一键自动保存/自动填充。没有读取苹果密码库。
- 剪贴板标记为隐藏/临时，30 秒后仅在剪贴板仍归本次复制所有时清除；锁定会话和正常退出时也清除。其他剪贴板历史工具仍可能有自己的行为。旧系统没有独立密码 App 时显示指引。旧文件密码需另行保留。
- 界面采用雾蓝与靛紫：渐变背景、拖放过渡、侧栏切换过渡、工作中锁图标呼吸效果；遵循减少动态效果、降低透明度及深浅色模式。Quick Look 和缩略图同步新配色。
- 官网版提供许可证页面和可配置授权客户端，支持服务端签名、设备密钥、三台席位、刷新、解绑和七天离线凭据。服务端基础及测试在 LicenseServer。未配置正式 HTTPS 地址和公钥，当前激活/购买显示尚未开放，不模拟成功；开发版也未开启付费限制。商店版不编译官网激活客户端，StoreKit 商品仍待配置。
- 新增 EasyLockWidget 小号/中号组件，提供保险箱、添加文件/文件夹、安全设置入口。默认隐藏数量；用户开启后只共享记录数量和更新时间。不是实时磁盘扫描结果，也不是保证所有已登记项目仍存在。没有应用专区或应用加密功能。

- 快捷 URL 仅允许四个固定入口，不接受路径、密码、查询参数或解密动作；添加文件仍通过主应用身份验证和选择确认。

### 面板重复显示修复

主场景改为唯一 Window，Finder 文件打开及小组件链接由应用代理进入现有请求队列，恢复/激活已有窗口而不是创建另一个 WindowGroup 实例。所有应用操作面板及独立提示共用一个 sheet 主机；活动面板不被后续请求替换。关闭期间保持占用状态，收到实际 onDismiss 回调后才展示下一面板。有活动面板时错误提示显示在面板内。

## 应用内私密预览

在文件列表选择一个密文，按空格或点击详情中的“预览”，验证密码、恢复密钥或 Touch ID 后查看。文件夹可展开选择内部文件。预览使用临时解密副本，原密文不变；关闭、锁定、正常退出时清理，异常退出后下次启动尝试清理。系统 Quick Look 和第三方预览扩展可能保留缓存，不能保证清除。Finder 预览与缩略图仍只显示固定的锁定图案。

### 预览显示（构建 10）

- Finder 空格预览采用原生隐私提示卡片，只检查文件头，不读取或解密内容。
- 缩略图按照实际绘图区域居中缩放，备用文件图标统一为蓝粉色锁图案。
