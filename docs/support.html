HELP & SUPPORT

保护之前，先做好备份。

遇到问题时，保留原始文件、密文和待恢复记录，避免反复替换或手动清理。

如何开始

设置主密码后，添加或拖入文件。首次操作可能需要授权所在文件夹。加密成功后名称增加 .easylock；双击密文或拖回应用进入解密流程。

忘记密码怎么办？

如果该文件在加密时已启用恢复密钥，可以用对应密钥恢复。否则开发者无法代为解密。Touch ID 不能替代异机恢复所需的密码或密钥。

打不开测试包怎么办？

当前包尚未完成 Developer ID 公证，其他 Mac 可能无法直接运行。请等待公证版本，或从源码在 Xcode 中构建。不要为了测试关闭系统安全保护。

改了文件后缀怎么办？

改后缀不会解密。将文件拖回 EasyLock，应用会检查密文标识；系统可能不会再默认用 EasyLock 打开它。

操作中断或恢复失败

重新打开应用，检查安全与设置中的恢复任务。先保存错误提示，不要手动删除事务目录。测试数据应始终有另外的备份。

反馈问题

请提供应用版本、macOS 版本、芯片类型、复现步骤及去除私人信息的错误提示。不要公开密码、恢复密钥、私人文件或完整私人路径。

提交问题测试验收步骤

Issues 是公开反馈渠道，不适合提交敏感资料。对于潜在安全问题，请先仅描述问题类型，请求维护者提供私下沟通方式。
