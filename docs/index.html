EasyLock 将文件与文件夹加密为 .easylock 文件。无需账号、无需激活，在本机完成保护与恢复。

查看测试版先阅读使用说明

当前是开发预览版。尚未完成正式公证、独立安全审查与完整实机验收。测试包使用开发签名，请仅使用有独立备份的测试资料。

从添加，到恢复

  1. 添加文件或文件夹。拖入应用，或从添加窗口选择，确认后在原位置生成密文。
  2. 预览只显示锁定提示。普通文件内容不会出现在 EasyLock 的密文预览中。
  3. 用对应凭据恢复。使用加密密码，或加密时已启用的恢复密钥。Touch ID 可作为本机快捷解锁方式。

使用前需要知道

更改主密码不会为已有文件更换密码；开发者无法找回遗失的密码或恢复密钥。加密不会清除历史备份、快照和其他明文副本。当前不提供应用程序加密。

支持 Intel 与 Apple Silicon 双架构构建，最低 macOS 14。实际兼容性仍在测试中。
