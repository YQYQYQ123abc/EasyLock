# EasyLock

免费的 macOS 离线文件加密工具，使用 Swift / SwiftUI 开发。无需账号、许可证或激活。

当前为开发预览版，尚未完成正式发行公证与完整实机验收。请使用有独立备份的测试文件。

- 使用 Xcode 打开 `EasyLock/EasyLock.xcodeproj`，选择 EasyLock scheme。

- [测试验收步骤](EasyLock/Distribution/Testing-Guide.md)
